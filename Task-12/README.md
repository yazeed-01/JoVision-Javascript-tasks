 ## Task-12
 
Create an HTML page that has two text fields with the title and place holder of 'Name', and 'Age'. And a button called "Submit". When pressed it should create an object of the form :
	{
    	"name": "the-name-you-entered",
    	"age" : "the-age-you-entered",
    	"timestamp" : "the-date-and-time-of-the-button-press"
	}
Then create a window popup that says "Your name is: " followed by the name you entered in the text field, and "Your age is: " followed by the age you entered in the text field and the timestamp of the button press. Note that you have to fill in the window's popup from the object you created.  [Javascript, Object creation, Object deconstruction]
